# Pêdiviyên bingehîn ên sepanên Windows-ê

* Nivîskar: Joseph Lee, Derek Riemer û yên din

Baştirkirina piştgiriyê ji bo sepan û kontrolên cûrbecûr li ser Windows 11.

GIRÎNG: Pêveka Windows App Essentials ji 14ê Cotmeha 2025an vir ve di moda lênêrîna kûr de ye (êdî bi awayekî çalak nayê pêşxistin). Ji bilî baştirkirina piştgirî û lihevhatina NVDAyê bi taybetmendî û guhertoyên Windowsê re, ti guhertin çênebûye.

Ev pêvek berhevokek ji modulên sepanên ji bo cûrbecûr sepanên nûjen ên Windows-ê ye, û her weha başkirin û rastkirinên ji bo hin kontrolên ku di Windows 11-ê de têne dîtin.

Têbînî:

* Ev pêvek hewceyê Windows 11 25H2 (avakirina 26200) an jî nûtir e.
* Demjimêra piştgiriya nûvekirina taybetmendiyê bi demjimêra piştgiriya xerîdar ve girêdayî ye (çapên Home, Pro, Pro Education, Pro for Workstations) û dibe ku pêvek piştgiriya nûvekirina taybetmendiyê berî bidawîbûna piştgiriya xerîdar biqedîne. Ji bo bêtir agahdarî û tarîxên piştgiriyê li <https://aka.ms/WindowsTargetVersioninfo> binêre.
* Her çend sazkirin mimkun be jî, ev pêvek piştgiriya guhertoyên Windows Enterprise LTSC (Kanala Xizmetkirina Demdirêj) û Windows Server nake.
* Ne hemû taybetmendiyên ji guhertoyên Windows Insider Preview dê werin piştgirîkirin, nemaze ji bo taybetmendiyên ku ji bo komek Windows Insiders hatine destnîşan kirin.

Ji bo navnîşek guhertinên ku di navbera her guhertoyên pêvekê de hatine çêkirin, li belgeya [changelogs for add-on releases][1] binêre.

[1]: https://github.com/josephsl/wintenapps/blob/main/changes.md
