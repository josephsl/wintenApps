# Windows Temel Uygulamalar

* Yazarlar: Joseph Lee, Derek Riemer ve diğerleri

ÖNEMLİ: Windows Temel Uygulamalar eklentisi, 14 Ekim 2025 itibarıyla resmi olarak kullanım ömrünün sonuna gelmiştir. NVDA'nın desteğini ve Windows özellikleri ve sürümleriyle uyumluluğunu geliştirmek dışında herhangi bir değişiklik yapılmayacaktır.

Bu eklenti, çeşitli modern Windows uygulamalarına yönelik uygulama modüllerinin yanı sıra Windows 11'de bulunan belirli kontrollere yönelik geliştirmeler ve düzeltmelerden oluşan bir koleksiyondur.

Notlar:

* Bu eklenti, Windows 11 25H2 (derleme 26200) veya sonrası  sürümleri gerektirir.
* Özellik güncellemesi destek süresi, tüketici destek süresine bağlıdır (Home, Pro, Pro Education, Pro for Workstations sürümleri) eklenti, tüketici desteğinin sona ermesinden önce bir özellik güncellemesi için desteği sonlandırabilir. Daha fazla bilgi ve destek tarihleri için <https://aka.ms/WindowsTargetVersioninfo> adresine bakın.
* Kurulum mümkün olsa da bu eklenti, Windows Enterprise LTSC'yi (Uzun Süreli Hizmet Kanalı) ve Windows Server sürümlerini desteklememektedir.
* Windows Insider Preview derlemelerindeki tüm özellikler desteklenmeyecektir; özellikle Windows Insider'ların bir alt kümesine sunulan özellikler için desteklenecektir.

Her eklenti sürümü arasında yapılan değişikliklerin bir listesi için [eklenti sürümleri için değişiklik günlükleri][1] belgesine bakın.

[1]: https://github.com/josephsl/wintenapps/blob/main/changes.md
